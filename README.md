
# House Price Prediction Using Machine Learning

## About the Project
This project predicts house prices using machine learning.
It compares Simple Linear Regression and Multiple Linear Regression.

## Dataset
Ames Housing Dataset
Source: https://raw.githubusercontent.com/emanrao/AmesHousing/master/train.csv

The dataset contains housing information from Ames, Iowa, USA.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Gradio

## Features Used
1. Overall Quality
2. Living Area
3. Number of Bedrooms
4. Number of Full Bathrooms
5. Year Built

## Machine Learning Models
- Simple Linear Regression
- Multiple Linear Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Interactive App
A simple app allows users to enter house details
and receive an estimated price.

## Limitations
The model uses housing data from Ames, Iowa.
Its predictions should not be treated as reliable estimates
for houses in India without suitable local data and testing.

## Learning Note
This project was developed as a beginner learning project
with AI-assisted coding and learning support.
